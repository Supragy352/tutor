Four Active Workstreams

Track 01 · Design

Unified Learner & Mission Control UX

  • Polish local learner cockpit (src/web/index.html): stage-scoped test results, live progress streaming, full ARIA accessibility, offline Markdown rendering.
  • Maintain the engineering computation pad visual language across docs/index.html and docs/dashboard.html.

Track 02 · Reasoning Handling

Configurable Multi-Tier AI Tutor

  • Decouple from Ollama/Claude-only lock-in: support OpenAI-compatible /v1/chat/completions endpoints and configurable CLI tutor commands.
  • Make reasoning/thinking token modes explicit and configurable (moving off hardcoded "think": false), separating fast diff feedback from deep Socratic hints.
  • Feed uncommitted diffs (git diff HEAD), exit statuses, and persisted hint history so reasoning models never review stale code.
Track 03 · Course Structure

Modular Schema & Multi-Mode Test Harness

  • Refactor single-file src/main.rs into clean Rust modules (cli, runner, llm, server, challenge, progress) with timeouts and safe pipe I/O.
  • Extend challenge.toml beyond stdin/stdout to support interactive REPL/PTY sessions, TCP/HTTP servers, filesystem assertions, and framebuffer/image checks.
  • Support multi-file course directories (stages/*.md, fixtures, language-specific test harnesses) while keeping tutor verify deterministic.
